#FS Manager

Your Files. Your Control.

Take control of your files with a modern and powerful file manager for Android.

Browse, organize, edit, view, and manage your files with a collection of useful tools, all in one place.

Built by F-Studio. Designed for simplicity.

---

More Than a File Manager

Everything you need to manage your files, right at your fingertips.

Smart File Management

Browse, copy, move, rename, delete, and organize your files and folders with ease.

Built-in File Viewers

Open images, documents, text files, and other supported formats without switching between multiple apps.

Media Player

Play your audio and video files directly inside FS Manager.

Text & Code Editor

Edit text files and source code with built-in editing tools.

Archive Manager

Create and extract supported compressed archives with ease.

Personalized Experience

Enjoy a clean interface with customizable appearance and dark and light themes.
